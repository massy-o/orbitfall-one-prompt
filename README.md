**ORBITFALL** — a neon one-button arcade game that an AI agent built from **one single prompt** (read it in [PROMPT.md](PROMPT.md)).

You are a glowing comet trapped in orbit around a dying star. One button — Space, click, or tap — flips you between the inner and outer orbit rings. Debris shards spiral in toward the star: switch rings at the last moment to dodge them, thread near misses to build a combo multiplier, and collect golden starlight motes to score. One hit and you shatter. The longer you survive, the faster everything comes.

- Single self-contained `index.html` — no build step, no dependencies, no assets
- Keyboard, mouse, and touch controls
- Combo system, particles, screen shake, synthesized sound-free arcade feel at 60 fps
- Open `index.html?demo=1` to watch the built-in autopilot play by itself

## Run it

```sh
node main.ts   # emits the playable game to ./output (or $MAKEFUN_OUTPUT_DIR)
# …or simply open index.html in any browser
```
